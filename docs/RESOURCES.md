# Curated resources

Checked 2026-11-07. Read assigned sections, not whole sites. The local lessons are the spine of the course.

| Resource | Use |
|---|---|
| [HDLBits problem index](https://hdlbits.01xz.net/wiki/Problem_sets) | Short explanations and browser-graded drills. Use the exact problem titles assigned in each lesson. |
| [Icarus getting started](https://steveicarus.github.io/iverilog/usage/getting_started.html) | Day 1: compile/run examples and module organization. |
| [Icarus simulation](https://steveicarus.github.io/iverilog/usage/simulation.html) | Day 3: simulation workflow and file organization. |
| [LaForest: ready/valid handshakes](https://fpgacpu.ca/fpga/handshake.html) | Day 6: Interfaces, Handshake Procedure, Avoiding Deadlocks and Livelocks. Revisit buffering tradeoffs during the project. |
| [Yosys synthesis starter](https://yosyshq.readthedocs.io/projects/yosys/en/latest/getting_started/example_synth.html) | Day 7: read design, hierarchy, process conversion, optimization and statistics. The tutorial's FPGA-specific commands are not the ASIC target for this project. |
| [Homebrew Icarus package](https://formulae.brew.sh/formula/icarus-verilog) | Verified macOS installation command. |

HDLBits exercises are external practice, not copied into this repository. Their interface is generally `top_module`; local exercises use the module names in their supplied starters. Skip unrelated K-maps, CPU-sized exercises, and language trivia this week.
